# Technical feasibility and decisions

1. **Rust/WebAssembly kernel**: the kernel owns files, task lifecycle, descriptors, traces, resource limits, snapshots, and WASI preview1 services in Rust linear memory. A small JSON-plus-bytes C ABI connects the UI and shell to that state. The main browser instance is authoritative; guests receive independent instances of the same compiled module. Rust 1.90.0 and Cargo.lock make builds reproducible. Browser clocks and entropy are the only kernel imports.
2. **browsercc 0.1.1**: inspected its actual package and [build scripts](https://github.com/BertalanD/browsercc/blob/main/build.sh). It contains Clang/LLD from LLVM 20.1.2 and WASI SDK 25 sysroot artifacts. The compiler has threads disabled. A small adapter adds the genuine linked binary to its return value, rather than only a compiled WebAssembly.Module, and creates the source parent directories before writing inputs. Sources never go to a compilation server.
3. **Browser-native Clang alternatives**: [browsercc](https://github.com/BertalanD/browsercc) is already a browser-native Clang distribution. emception would supply a much larger Emscripten environment; DIORAMA only needs C/WASI. No native host compiler or server-backed compiler substitutes for the browser path.
4. **v86 evaluated, omitted**: [v86](https://github.com/copy/v86) emulates a PC and can boot guest operating systems. A Linux guest would duplicate process and filesystem abstractions and obscure the intended custom runtime. No Linux VM is necessary for the accepted computing core.
5. **WASI preview1 in WASM**: service semantics run inside the Rust kernel. The guest worker only marshals guest pointers and results between two WASM memories, supplies browser clocks/entropy, and sends actual trace/descriptor data to the inspector. Unsupported services return ENOTSUP; imports outside preview1, unbounded memory, and shared memory are rejected. No SharedArrayBuffer is required.
6. **YOLO26**: use the official [Ultralytics inference browser package](https://github.com/ultralytics/inference/tree/main/web), version 0.0.51, with ONNX models from the v8.4.0 asset release. The package's Rust processing remains intact. Its DOM script loader is replaced with an ES-module worker loader for the same ONNX Runtime Web 1.27.0 files. CPU runs with numThreads=1. Upstream domain telemetry is disabled. Model artifacts are hosted same-origin because GitHub release downloads lack browser CORS headers.
7. **SAM3 removed**: the owner cancelled SAM3 on 2026-10-13 because of its size. No SAM3 integration, service, download, or checkpoint is part of the accepted project. Local instance segmentation is explicitly YOLO26n-seg.
8. **GitHub Pages**: Vite base is /diorama/. All heavyweight paths derive from BASE_URL. CI rebuilds assets, tests the production subpath, and runs the real compiler/model acceptance tests before uploading the Pages artifact.
9. **Security**: guests receive only selected WASI functions and a snapshot of the VFS. Filesystem deltas merge on successful completion. Worker cancellation and a 10-second timeout protect the UI from loops. The compiler has a separate 180-second timeout to cover first-use asset loading.
